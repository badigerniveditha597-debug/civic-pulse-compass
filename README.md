# Civic Pulse Compass

Build a professional, modern and fully responsive web application called "CivicPulse AI".

Tagline: From Complaints to Action.

PURPOSE:
An AI-powered civic complaint management platform that allows citizens to report public problems and helps authorities prioritize, analyze and resolve them.

DESIGN:

Modern smart-city technology dashboard.

White background with navy blue and teal accents.

Professional typography.

Clean cards, charts and icons.

Responsive desktop and mobile layouts.

Easy-to-use interface.

CREATE TWO MAIN SECTIONS:

A. CITIZEN PORTAL
Create a complaint submission page containing:

Citizen name (optional).

Complaint title.

Description.

Category dropdown: Road Damage, Garbage, Waterlogging, Streetlight, Water Supply, Other.

Image upload.

Location/address.

Submit complaint button.

Generate a unique complaint ID after submission.

My Complaints page to track complaint status.

B. ADMIN DASHBOARD
Create an admin dashboard containing:

Total complaints.

Pending complaints.

In-progress complaints.

Resolved complaints.

Critical complaints.

Complaint list with search and filters.

Priority labels.

Category-wise statistics.

Location-wise complaint statistics.

Complaint details page.

Assign department option.

Update complaint status option.

Add realistic sample complaint records for demonstration.

IMPORTANT:
Make the design polished but prioritize working functionality.
Use reusable components and clean architecture.
Do not create buttons that do nothing.
Keep the citizen portal simple and easy to use.
